v3.0.0 — today
major rebuild: the signal is cleaner now
  • fixed login session restore — was silently failing on every reload
  • fixed registered accounts being wiped on every boot
  • fixed async/sync mismatch in JAA encryption layer
  • complete admin panel with features registry, plugins, BPE monitor
  • word lattice — resonance-weighted visual of your signal vocabulary
  • AI resonance assistant powered by Claude
  • meteditor: site editor, causal nexus graph, snapshots
  • human language metrics — no raw numbers, descriptions instead
  • friends system: soul mates, kindred spirits, twin flames, signal neighbours
  • gallery with upload limits, tags, and privacy controls
  • delta-driven depth adaptation — UI adjusts to your resonance level
  • cookie-based persistent sessions (7 days)
  • Causal Nexus BroadcastChannel bridge integration
  • UUID-tracked feature registry hooked to admin panel
  • plugins page with enable/disable
  • bug report system with severity tagging
