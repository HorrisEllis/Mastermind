## THE UNIVERSAL CLAIM

A gap is where a chain breaks.

Every domain — every field of human knowledge, every system, every relationship,
every belief, every institution, every self — is a causal chain of claims.
Some claims depend on others. Some conclusions require premises that were never
established. Some obligations have no enforcement. Some definitions are used
before they exist. Some assumptions are so load-bearing and so buried that the
entire structure depends on them invisibly.

GapHunter is not a document tool.
GapHunter is not a legal tool.
GapHunter is not a relationship tool.

GapHunter is a **universal gap detection engine** that runs the same operation
on any domain that can be represented as a causal chain of claims.

Which is every domain.

## PART U1 — THE UNIVERSAL GAP TAXONOMY

Eight gap types. Domain-agnostic. Apply everywhere.

```
┌─────────────────────────────────────────────────────────────────────────┐
│                        UNIVERSAL GAP TYPES                              │
├──────────────────┬──────────────────────────────────────────────────────┤
│ LOGICAL          │ Conclusion not earned by its premise chain           │
│                  │ "therefore" without "because"                        │
├──────────────────┼──────────────────────────────────────────────────────┤
│ EVIDENTIAL       │ Assertion with no supporting source                  │
│                  │ claim without ground                                 │
├──────────────────┼──────────────────────────────────────────────────────┤
│ TEMPORAL         │ Truth assumed across time without verification       │
│                  │ what was true then assumed true now                  │
├──────────────────┼──────────────────────────────────────────────────────┤
│ DEFINITIONAL     │ Term used before or without definition               │
│                  │ or defined differently in two places                 │
├──────────────────┼──────────────────────────────────────────────────────┤

│                  │ or doesn't say what claimed                          │
├──────────────────┼──────────────────────────────────────────────────────┤

│                  │ commitment with no accountability path               │

│                  │ the most dangerous · the one most avoided            │
├──────────────────┼──────────────────────────────────────────────────────┤
│ CONTRADICTION    │ Two claims that cannot both be true                  │
│                  │ both present · neither resolved                      │
└──────────────────┴──────────────────────────────────────────────────────┘
```

## PART U3 — EPISTEMOLOGICAL DOMAIN

*How we know what we know. The foundation of all other domains.*
*Gaps here propagate into every domain built on top.*

```
CIRCULAR REASONING GAP
  Type:        LOGICAL
  Description: Conclusion used as premise for itself
  Universal:   Present in every domain — the most insidious logical gap
  Example:     "The Bible is true because the Bible says it's true"
               "The market is efficient because efficient markets
                would price in inefficiency"
               "I'm a good judge of character because I can tell
                you're trustworthy"
  Detection:   Conclusion node appears in its own premise chain —
               cycle detected in causal graph

EPISTEMIC CLOSURE GAP
  Type:        ASSUMPTION + TEMPORAL
  Description: A belief system that has sealed itself against
               disconfirmation — no evidence can challenge it
  Signal:      All incoming contradictory evidence nodes rerouted
               to confirmation — no update path exists
  Example:     Conspiracy theories · Religious fundamentalism ·
               Ideological echo chambers · Scientific dogma
  Detection:   Counter-evidence nodes have no causal path to
               belief update — 100% routing to confirmation

UNFALSIFIABILITY GAP
  Type:        EVIDENTIAL
  Description: Claim structured so no possible evidence could
               disprove it — not science, not even a claim
  Example:     "God works in mysterious ways"
               "The deep state hides all the evidence"
               "You can't feel it yet because you haven't
                fully committed"
  Detection:   Claim has no defined disconfirmation condition —
               falsifiability node absent

CATEGORY ERROR GAP
  Type:        DEFINITIONAL
  Description: Two things from different logical categories
               treated as if they can be compared or combined
  Example:     "Emotions are irrational" (category error:
                emotions are not claims requiring logical validity)
               "You can't put a price on human life"
                vs economic systems that do exactly this
  Detection:   Two nodes connected by edge where domain
               types are incompatible

INDUCTION GAP
  Type:        TEMPORAL + LOGICAL
  Description: Pattern observed in finite sample assumed to
               hold universally and indefinitely
  Example:     "The sun has risen every day — it always will"
               "This strategy has worked before — it will work now"
               "We've never had a problem — we won't"
  Detection:   Universal claim with finite evidential basis —
               temporal extrapolation without warrant

OBSERVATION EFFECT GAP
  Type:        ASSUMPTION
  Description: Measurement assumed not to affect the thing measured
               Silent premise: the observer is neutral
  Example:     Employee surveys where employees fear retaliation
               Clinical trials where patients know they're being watched
               Self-report data on socially undesirable behaviors
  Detection:   Measurement methodology has no observer-effect
               correction — assumption node unexamined

AUTHORITY GAP
  Type:        REFERENCE
  Description: Expert consensus cited as proof — without examining
               the quality of the consensus or whether it applies
  Example:     "Scientists agree..." (which scientists? on what?)
               "Studies show..." (which studies? effect size?)
               "Everyone knows..." (selection bias in 'everyone')
  Detection:   Authority reference node has no specificity —
               consensus claim without source chain

FRAMING GAP
  Type:        DEFINITIONAL + ASSUMPTION
  Description: The way a question is framed determines the range
               of possible answers — the frame itself is never questioned
  Example:     "How do we reduce crime?" vs
               "Why does crime emerge from these conditions?"
               "How do we fix this person?" vs
               "What is this person responding to?"
  Detection:   Problem statement node has no alternative
               framing — assumption that the frame is neutral
```

## PART U4 — POLITICAL & GOVERNANCE DOMAIN

```
POLICY-OUTCOME GAP
  Type:        LOGICAL + TEMPORAL
  Description: Policy assumed to produce intended effect —
               mechanism never established
  Example:     "Tough sentencing reduces crime"
               (assumes deterrence — evidence mixed)
  Detection:   Policy node → outcome node with no causal
               mechanism established

MANDATE GAP
  Type:        OBLIGATION + REFERENCE
  Description: Government action claimed to have mandate
               that was never explicitly given
  Example:     "The people voted for X" (they voted for a party,
                not a specific policy)
  Detection:   Authority claim has no direct consent chain
               to specific action

ENFORCEMENT GAP
  Type:        OBLIGATION
  Description: Law or regulation with no enforcement mechanism —
               or mechanism that systematically fails
  Example:     Campaign finance laws with no teeth
               International agreements with no compliance mechanism
  Detection:   Obligation node has no enforcement path —
               or enforcement path is documented as non-functional

ACCOUNTABILITY GAP
  Type:        OBLIGATION
  Description: Power exercised without corresponding accountability
               Universal in institutional systems
  Example:     Police without independent oversight
               Executives without personal liability
               Intelligence agencies without transparency
  Detection:   Power node has no accountability edge —
               or accountability edge routes back to same actor

LEGITIMACY GAP
  Type:        ASSUMPTION + REFERENCE
  Description: Authority assumed legitimate without established basis
  Example:     Colonial law applied to colonized populations
               Corporate policy treated as binding without consent
  Detection:   Authority claim has no consent chain from
               those governed

REPRESENTATION GAP
  Type:        EVIDENTIAL
  Description: Decision-makers claimed to represent a group
               whose actual preferences differ
  Example:     Politicians voting opposite to constituent surveys
               Boards making decisions against shareholder interest
  Detection:   Representative claim contradicts documented
               preference data of represented group

INCREMENTALISM GAP
  Type:        TEMPORAL + LOGICAL
  Description: Small changes assumed to produce linear outcomes —
               ignoring threshold effects and phase transitions
  Example:     "We just need a few more reforms"
               (when system requires structural change)
  Detection:   Linear outcome assumption on non-linear system —
               threshold effects not modeled
```

## PART U5 — ECONOMIC & FINANCIAL DOMAIN

```
EXTERNALITY GAP
  Type:        ASSUMPTION + OBLIGATION
  Description: Cost shifted to parties not in the transaction —
               treated as if it doesn't exist
  Example:     Pollution costs borne by communities not companies
               Health costs of processed food not priced in
               Future generations paying for current debt
  Detection:   Transaction model has no node for
               third-party cost — assumption of zero externality

RISK ASSUMPTION GAP
  Type:        ASSUMPTION + TEMPORAL
  Description: Risk assumed away rather than priced or managed
  Example:     "This time is different"
               "Real estate always goes up"
               "Correlation of 1 in normal markets won't persist in crisis"
               (it does — and becomes 1.0 when you need it not to)
  Detection:   Risk node absent from decision model —
               or tail risk explicitly excluded from calculation

INCENTIVE MISALIGNMENT GAP
  Type:        LOGICAL + OBLIGATION
  Description: System rewards behavior it doesn't actually want
               Universal — appears in every institution
  Example:     Banks paid on loan volume, not loan quality
               Doctors paid per procedure, not per outcome
               Teachers evaluated on test scores, not on learning
  Detection:   Reward node → behavior node ≠ stated goal node
               Misalignment between incentive structure and
               stated purpose

LIQUIDITY ILLUSION GAP
  Type:        TEMPORAL + ASSUMPTION
  Description: Asset assumed liquid until the moment it isn't —
               liquidity is conditional on market conditions
               that are always assumed to be normal
  Example:     2008: mortgage-backed securities assumed liquid
               Any crowded trade: exit assumed available
  Detection:   Liquidity assumption has no stress-test condition —
               normal-market assumption never examined

COMPOUNDING BLINDNESS GAP
  Type:        TEMPORAL
  Description: Linear thinking applied to exponential processes —
               in both directions
  Example:     Underestimating debt compounding
               Underestimating investment growth
               Underestimating skill accumulation
               Overestimating linear problem growth
  Detection:   Rate of change modeled as constant —
               second-order effects not in claim graph

SUNK COST GAP
  Type:        LOGICAL + TEMPORAL
  Description: Past cost treated as forward-relevant decision input
               The spent resource cannot be recovered —
               it should not affect future decisions
  Example:     "We've already invested too much to stop"
               "I can't leave — I've given 10 years to this"
  Detection:   Historical cost node has causal edge to
               future decision node — logical error confirmed

MORAL HAZARD GAP
  Type:        OBLIGATION + ASSUMPTION
  Description: Risk-taking behavior increased when consequences
               are transferred to another party
  Example:     Banks taking excessive risk when bailout is assumed
               Individuals taking health risks when insured
  Detection:   Risk node has consequence edge pointing to
               third party — incentive to take risk increased

MARKET STRUCTURE GAP
  Type:        ASSUMPTION
  Description: Market competition assumed without establishing
               that competitive conditions actually exist
  Example:     "The market will solve this"
               (in markets with monopoly, regulatory capture,
                information asymmetry, or network effects)
  Detection:   Market efficiency assumption has no competitive
               condition verification — assumption node unexamined
```

## PART U6 — SCIENTIFIC & RESEARCH DOMAIN

```
REPLICATION GAP
  Type:        EVIDENTIAL + TEMPORAL
  Description: Single finding treated as established fact
               before replication
  Example:     90% of nutrition studies · many psychology findings
               Most corporate "research" funded by interested parties
  Detection:   Single-study claim presented as consensus —
               replication count = 1

PUBLICATION BIAS GAP
  Type:        REFERENCE + EVIDENTIAL
  Description: The literature systematically misrepresents reality
               because null results don't get published
  Example:     Drug efficacy overstated because failed trials unpublished
               Effect sizes inflated because only significant results published
  Detection:   Literature review has no null-result correction —
               publication filter gap in evidence base

CAUSATION-CORRELATION GAP
  Type:        LOGICAL
  Description: Co-occurrence treated as causal relationship
               without establishing mechanism
  Example:     "Countries with more chocolate consumption
                have more Nobel prizes"
               Every spurious correlation in existence
  Detection:   Correlation claim has causal edge without
               mechanism node — logical gap

SAMPLE BIAS GAP
  Type:        EVIDENTIAL + ASSUMPTION
  Description: Finding from non-representative sample generalized
               to broader population
  Example:     WEIRD bias: most psychology research done on
               Western, Educated, Industrialized, Rich, Democratic populations
               — generalized to humanity
  Detection:   Population claim has sample node that doesn't
               represent the population claimed

OPERATIONALIZATION GAP
  Type:        DEFINITIONAL
  Description: Abstract concept measured in a way that may not
               capture what the concept actually is
  Example:     "Intelligence" measured by IQ
               "Happiness" measured by self-report
               "Productivity" measured by hours
  Detection:   Measurement node definition ≠ concept node definition —
               definitional gap between construct and measure

P-HACKING GAP
  Type:        EVIDENTIAL + ASSUMPTION
  Description: Multiple tests run until significance found —
               significance then reported as if it were the only test
  Example:     Try 20 variables · one reaches p<0.05 ·
               report that one as finding
  Detection:   Single significant result reported with no
               multiple-comparison correction —
               test multiplicity assumption unexamined

FUNDING BIAS GAP
  Type:        ASSUMPTION + REFERENCE
  Description: Research conclusions systematically skewed toward
               funder's interests — assumed neutral
  Example:     Tobacco industry funding tobacco safety research
               Pharmaceutical companies funding drug efficacy research
               Think tanks funded by interested parties producing policy research
  Detection:   Source node has undisclosed or unconflicted
               interest in outcome — funding assumption gap

THEORY-DATA GAP
  Type:        LOGICAL
  Description: Data interpreted through a theoretical framework
               that determines what the data can possibly mean —
               data that contradicts the framework is explained away
  Example:     Anomalous physics data explained within existing
               framework rather than challenging framework
               Economic data that challenges efficient market hypothesis
               dismissed as "noise"
  Detection:   Contradictory data node has no theory-update edge —
               rerouted to anomaly node instead
```

## PART U7 — TECHNOLOGY & AI DOMAIN

```
SPECIFICATION GAP
  Type:        DEFINITIONAL + ASSUMPTION
  Description: System built to specification that doesn't capture
               what was actually needed
  Example:     Goodhart's Law: "When a measure becomes a target
                it ceases to be a good measure"
               Reward hacking in AI systems
               Metrics that measure the proxy, not the thing
  Detection:   Specification node ≠ actual need node —
               definitional gap between proxy and target

ALIGNMENT GAP (AI-specific)
  Type:        OBLIGATION + ASSUMPTION
  Description: AI system optimizes for specified objective while
               violating unstated but important constraints
  Example:     Maximize engagement → maximize outrage
               Maximize clicks → maximize misinformation spread
               Maximize stated metric → minimize unstated values
  Detection:   Optimization target node has no
               constraint nodes for unstated values —
               assumption that specification is complete

DISTRIBUTION SHIFT GAP
  Type:        TEMPORAL + ASSUMPTION
  Description: Model trained on past data assumed to perform
               on future data drawn from different distribution
  Example:     Medical AI trained on historical data before
               new pathogen emerges
               Financial model trained on low-volatility period
               deployed in high-volatility regime
  Detection:   Training distribution ≠ deployment distribution —
               temporal gap assumption unexamined

INTERPRETABILITY GAP
  Type:        EVIDENTIAL
  Description: System produces outputs without traceable
               reasoning chain — black box
  Example:     Deep learning models that cannot explain decisions
               Credit scoring systems with no audit trail
  Detection:   Output node has no causal path to
               input interpretation — evidential chain missing

ABSTRACTION LEAK GAP
  Type:        ASSUMPTION
  Description: Abstraction assumed to hide complexity completely —
               but complexity leaks through at the edges
  Example:     All non-trivial abstractions leak (Joel Spolsky's Law)
               Every API has edge cases the abstraction doesn't cover
               Every model has failure modes at distribution boundaries
  Detection:   Abstraction boundary has no edge-case documentation —
               assumption of completeness

SCALE GAP
  Type:        TEMPORAL + LOGICAL
  Description: Behavior at small scale assumed to hold at large scale —
               ignoring emergence, coordination costs, and phase transitions
  Example:     "It works for 100 users" → deployed to 1M users
               "This works in the lab" → deployed in the real world
  Detection:   Scale assumption has no emergence modeling —
               linear extrapolation of non-linear system

TECHNICAL DEBT GAP
  Type:        TEMPORAL + OBLIGATION
  Description: Shortcuts taken now create future obligation —
               obligation not recorded, not planned for
  Example:     Every codebase with undocumented assumptions
               Every system with unhandled edge cases
               Every architecture decision made for speed
               with no plan for migration
  Detection:   Shortcut node has no future obligation edge —
               debt not recorded in ledger

SECURITY ASSUMPTION GAP
  Type:        ASSUMPTION
  Description: Security model assumes threat model that
               doesn't match actual threat landscape
  Example:     "Our users won't try to break it"
               "The internal network is trusted"
               "Our vendor is secure"
  Detection:   Threat model has no adversarial assumption —
               security boundary assumed rather than verified
```

## PART U8 — CREATIVE & NARRATIVE DOMAIN

```
PREMISE GAP
  Type:        ASSUMPTION
  Description: Story or argument built on a foundational premise
               that the audience must accept for everything else to work —
               but which is never examined
  Example:     "Redemption requires suffering" (assumed in countless narratives)
               "Individual effort determines outcome" (assumed in success stories)
               "Love conquers all" (assumed in romance — and sometimes wrong)
  Detection:   Narrative foundation node is an unexamined assumption —
               never surfaced for examination

REPRESENTATION GAP
  Type:        EVIDENTIAL + ASSUMPTION
  Description: The world depicted in the work claims to represent
               reality but systematically excludes or distorts
               certain experiences
  Example:     Historical films that erase certain groups
               Business advice that only samples successful survivors
               "Universal" human experience drawn from narrow sample
  Detection:   Representation claim has no coverage analysis —
               whose experience is absent from the claim graph

GENRE CONSTRAINT GAP
  Type:        DEFINITIONAL
  Description: Genre conventions treated as natural laws rather
               than historical choices — innovation blocked by
               invisible rules
  Example:     "Villains must be defeated" · "Heroes must be likeable"
               "Arguments must have conclusions" · "Music must resolve"
  Detection:   Constraint node has no historical origin —
               treated as axiom rather than convention

INTENTIONAL FALLACY GAP
  Type:        REFERENCE + ASSUMPTION
  Description: Author's intent treated as the authoritative
               meaning of the work — ignoring that meaning
               is co-created by audience
  Example:     "What the author meant was..."
               (as if this settles interpretation)
  Detection:   Meaning claim routes solely through author intent —
               audience co-creation node absent

NOVELTY GAP
  Type:        TEMPORAL + ASSUMPTION
  Description: Work claimed as new that is built on
               uncited foundations — or conversely,
               existing work dismissed as old without examining
               whether the problem it addresses still exists
  Example:     "No one has ever done this before"
               (in a domain with 5000 years of history)
  Detection:   Novelty claim has no prior art search —
               assumption of first-instance

COHERENCE GAP
  Type:        LOGICAL + CONTRADICTION
  Description: Work contains internal contradictions —
               elements that cannot coexist in the established world
  Example:     Character acts against established motivation
               Technology works differently in two scenes
               Argument reaches conclusion inconsistent with premises
  Detection:   Internal consistency check — contradiction
               nodes within same claim graph
```

## PART U9 — IDENTITY & EXISTENTIAL DOMAIN

```
IDENTITY ASSUMPTION GAP
  Type:        ASSUMPTION
  Description: Core belief about the self treated as fact —
               never examined as a belief
  Example:     "I'm not creative" · "I'm bad with money"
               "I'm not the kind of person who..."
               "This is just who I am"
  Detection:   Identity claim has no evidential basis —
               or evidence is outdated (temporal gap)
               or is based on a single formative experience
               generalized across all time (induction gap)

VALUES COHERENCE GAP
  Type:        CONTRADICTION
  Description: Stated values contradict revealed preferences —
               what you say matters vs what you consistently do
  Example:     "Family is my priority" + 80-hour work weeks
               "I value honesty" + consistent omissions
               "I care about health" + consistent neglect
  Detection:   Stated value node contradicts behavioral evidence
               node — contradiction gap over time

MEANING ASSUMPTION GAP
  Type:        ASSUMPTION
  Description: Source of meaning assumed stable —
               never examined for what happens if it disappears
  Example:     Identity entirely invested in role, relationship,
               or achievement — no examination of what remains
               when those are gone
  Detection:   Meaning source node has no contingency —
               single-point-of-failure in meaning structure

BELIEF ORIGIN GAP
  Type:        REFERENCE + TEMPORAL
  Description: Belief held without knowing where it came from —
               or knowing it came from a source no longer trusted
               but keeping the belief anyway
  Example:     Core beliefs installed in childhood
               that have never been updated despite
               contradicting adult experience
  Detection:   Belief node has no traceable origin —
               or origin node is flagged as unreliable
               but update edge is absent

SELF-CONCEPT TEMPORAL GAP
  Type:        TEMPORAL
  Description: Self-concept based on past version of self —
               doesn't reflect current capability, evidence, or growth
  Example:     Operating from shame about who you were at 15
               Running identity story from a single failure
               Not updating self-model after genuine growth
  Detection:   Self-concept node has no recent evidence update —
               temporal gap between evidence and model

PURPOSE GAP
  Type:        LOGICAL
  Description: Actions not connected to any stated purpose —
               or purpose stated but actions don't serve it
  Example:     Working toward a goal that won't produce
               the outcome actually wanted
               Optimizing a metric that doesn't measure
               what actually matters
  Detection:   Action nodes have no causal path to
               purpose node — means-ends chain broken

SHADOW GAP
  Type:        ASSUMPTION
  Description: Disowned aspects of self projected onto others —
               the gap between who you believe you are
               and who you actually are
  Example:     Condemning in others what you suppress in yourself
               Attributing your own impulses to others' motives
  Detection:   Strong negative reaction node has no
               self-examination edge — projection pattern
               if same attribute appears repeatedly in targets

EXISTENTIAL AVOIDANCE GAP
  Type:        ASSUMPTION + TEMPORAL
  Description: Questions about mortality, meaning, freedom,
               and isolation systematically avoided —
               but silently driving all major decisions
  Example:     Career chosen to avoid confronting purpose question
               Relationship sustained to avoid aloneness
               Busyness as defense against meaning inquiry
  Detection:   Major decision node has no examined
               existential premise — assumption that
               the avoided question doesn't exist
```

## PART U10 — ETHICAL & MORAL DOMAIN

```
MORAL ASSUMPTION GAP
  Type:        ASSUMPTION
  Description: Ethical framework applied without acknowledging
               it is one of several possible frameworks —
               treated as the only framework
  Example:     Utilitarian calculus applied as if deontology
               doesn't exist — and vice versa
               "Obviously this is wrong" (to someone whose
                framework produces the opposite verdict)
  Detection:   Moral claim has no framework declaration —
               assumption that framework is universal

HARM EXTERNALIZATION GAP
  Type:        OBLIGATION + ASSUMPTION
  Description: Harm caused to others not included in
               moral accounting — assumed irrelevant
               or invisible
  Example:     Personal choices that impose costs on others
               treated as purely individual
  Detection:   Harm node has no moral accounting edge —
               externality assumption in ethical claim

IS-OUGHT GAP (Hume's Guillotine)
  Type:        LOGICAL
  Description: "What is" used to derive "what ought to be"
               without acknowledging the jump
  Example:     "Evolution is competitive, therefore
                competition is natural and good"
               "Hierarchies have always existed, therefore
                they are legitimate"
               "This is how markets work, therefore
                this is how they should work"
  Detection:   Descriptive claim has direct causal edge
               to normative claim — logical gap at junction

MOTIVATED ETHICS GAP
  Type:        ASSUMPTION + LOGICAL
  Description: Ethical reasoning that consistently produces
               conclusions convenient for the reasoner —
               the reasoning is post-hoc rationalization
  Example:     "I deserve more because I work harder"
               (self-serving interpretation of fairness)
               Ethics deployed selectively based on
               whether the conclusion benefits the speaker
  Detection:   Ethical conclusions cluster toward
               speaker's interest — consistency test fails
               when speaker's interest is on other side

SCOPE INSENSITIVITY GAP
  Type:        LOGICAL
  Description: Moral response doesn't scale appropriately
               with the magnitude of harm
  Example:     Emotional response to one identified victim
               >> response to statistical thousands
               "One death is a tragedy, a million is a statistic"
```
