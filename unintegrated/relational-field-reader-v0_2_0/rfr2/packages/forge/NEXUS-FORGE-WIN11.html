About NEXUS/FORGE
Nexus/Forge
v1.0.0 — Windows 11 · Electron · SISO Architecture
Enterprise AI coding suite built on the SISO (Stream In, Stream Out) pure functional framework by Jonathan Bailey (2025).

Every action is an event. Every mutation is a Gate. The DOM is the state. Nothing is duplicated. Everything is verifiable.

Optimized for: deepseek-coder-v2:16b-lite-instruct-q4_K_M on AMD R7 3700x with 16GB RAM.
Architecture: SISO Event/Gate/Stream + SISO/UI (DOM as state)
AI: Ollama primary · Guardian web ext fallback
Editor: Monaco Editor 0.45
Token budget: 4096 (enforced per request)
Gates registered: 11 UI gates + AI pipeline gates
